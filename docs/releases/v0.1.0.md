The first standalone Crontab Guru Dashboard release separates the local cron
manager, web UI, and dashboard MCP server from Cronitor CLI.

Each native release includes `crontab-dashboard` and Cronitor CLI 33.8. Monitored
jobs use the CLI; local cron management works without a Cronitor account. Existing
`CRONITOR_*` settings and `/etc/cronitor/cronitor.json` remain compatible.

Linux and macOS bundles include a SHA-256 checksum. Docker images include cron,
the dashboard, and the pinned CLI, and persist configuration and crontabs.
